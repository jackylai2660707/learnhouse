## 4. 自建代码执行器

### 为什么替代 Judge0

宿主机是 cgroup v2 (`cgroup2fs`)。Judge0 的 isolate 后端依赖 cgroup v1；切换需要内核参数和整机重启，而此机器还运行 Caddy、邮件、支付、算法交易等多个无关服务。

外部 Judge0 也有两个实测 P0：

1. API 未传 `base64_encoded=true`，中文源码/输出会失败；
2. 外部主机 Node 运行时 `Illegal instruction (core dumped)`。

### 文件

```text
docker/executor/app.py
docker/executor/Dockerfile
```

## 7. 本地 embeddings 和 RAG

### 为什么改

```text
  -> docker/embeddings FastAPI service

  -> 768-dim vectors
```
